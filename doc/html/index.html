    Class and Module Index

    • PdfSolidConversion::Conversion: PDF conversion entry points for Word, RTF, Excel, PowerPoint, HTML, image, searchable PDF, TXT, JSON, Markdown, and OFD.
    • PdfSolidConversion::ConvertOptions: conversion options for OCR, AI layout/table recognition, page ranges, image settings, Excel/HTML output modes, and text/table behavior.
    • PdfSolidConversion::ConvertCallback: progress and cancel callback wrapper for native conversion tasks.
    • PdfSolidConversion::ErrorCode: native SDK result codes.
    • Class and Module Index: full generated index for modules, classes, constants, attributes, and methods.

    Basic Usage

    require "pdfsolid_conversion"

license_code = PdfSolidConversion::LibraryManager.license_verify(
  license_key,
  "",
  "com.pdfsolid.conversion.demo"
)
raise "license verification failed: #{license_code}" unless license_code == PdfSolidConversion::ErrorCode::SUCCESS

begin
  PdfSolidConversion::LibraryManager.initialize_sdk
  PdfSolidConversion::LibraryManager.set_logger(false, true)

  options = PdfSolidConversion::ConvertOptions.new
  options.enable_ocr = false
  options.transparent_text = true
  options.languages = [PdfSolidConversion::OCRLanguage::CHINESE]

  callback = PdfSolidConversion::ConvertCallback.new(
    progress: ->(current, total) { puts "progress: #{current}/#{total}" },
    cancel: -> { false }
  )

  result = PdfSolidConversion::Conversion.start_pdf_to_word(
    "/path/to/input.pdf",
    "",
    "/path/to/output.docx",
    options,
    callback: callback
  )
ensure
  PdfSolidConversion::LibraryManager.release
end

    Runtime Notes

    • The packaged Ruby SDK currently targets Linux x86_64.
    • The gem loads native libraries from lib/pdfsolid_conversion/vendor/linux-x86_64.
    • initialize_sdk uses the packaged resource/fonts directory when no resource path is provided.
    • Call release after conversions complete so native SDK resources are freed.
