    PdfSolidConversion Modules

    PdfSolidConversion is the top-level namespace for the Ruby binding. The modules and classes below are the main public API surfaces exposed by the Ruby SDK.

    Module List

    NConversion Provides PDF conversion entry points for Word, RTF, Excel, PowerPoint, HTML, image, searchable PDF, TXT, JSON, Markdown, and OFD.
    CConvertOptions Defines conversion options for OCR, AI layout analysis, table recognition, page ranges, image output, Excel output, and HTML output.
    CConvertCallback Wraps progress and cancel callbacks passed to native conversion tasks.
    NErrorCode Defines native SDK result codes returned by license verification and conversion APIs.

    Enumerations

    NOCRLanguage OCR language constants.
    NPageLayoutMode PDF layout reconstruction mode constants.
    NOCROption OCR processing option constants.
    NImageColorMode Image color mode constants.
    NImageType Image output format constants.
    NExcelWorksheetOption Excel worksheet layout constants.
    NHtmlOption HTML output mode constants.

    Internal Native Binding

    NNative Loads packaged Linux x86_64 native libraries and declares the low-level C API signatures used by the Ruby wrapper.
